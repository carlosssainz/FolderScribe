### ExclusionMatcher (dominio)

**Ubicación:** `src/folderscribe/domain/exclusion.py`

```python
import fnmatch

class ExclusionMatcher:
    def __init__(self, rules: tuple[ExclusionRule, ...]) -> None:
        self._rules = rules

    def is_excluded(self, relative_path: str) -> tuple[bool, ExclusionRule | None]:
        for rule in self._rules:
            if "/" not in rule.pattern:
                basename = relative_path.rsplit("/", 1)[-1]
                if fnmatch.fnmatch(basename, rule.pattern):
                    return True, rule
            else:
                if fnmatch.fnmatch(relative_path, rule.pattern):
                    return True, rule
        return False, None
```

### ContentHasher (nuevo en V3)

**Interfaz:** `src/folderscribe/domain/interfaces.py`

```python
class ContentHasher(ABC):
    @abstractmethod
    def compute_hash(self, path: Path) -> ContentHash: ...
```

**Implementación:** `src/folderscribe/infrastructure/hasher.py`

`StreamingHasher` lee archivos por bloques de 64 KB, calcula SHA-256, verifica
estabilidad del archivo (stat previo y posterior) y maneja errores sin detener
el proceso.

## Esquema SQLite (V3)

Todas las tablas se crean con `CREATE TABLE IF NOT EXISTS`. La versión del
esquema se almacena en `schema_version`.

Las fechas se serializan en formato ISO 8601 UTC.

**Índices:**

- `idx_content_hashes_entry` sobre `entry_id`
- `idx_content_hashes_hash` sobre `hash_sha256`
- `idx_content_hashes_session` sobre `session_id`

### Significado de los estados de huella

| Estado | Descripción |
|--------|-------------|
| `pending` | Pendiente de procesar |
| `computed` | SHA-256 recién calculado |
| `reused` | Huella existente reutilizada (mismo tamaño y fecha de modificación) |
| `skipped` | Omitido (directorio, symlink, archivo sin metadatos) |
| `modified_during_read` | El archivo cambió mientras se leía; no se acepta la huella |
| `error` | Error de lectura, permisos, o archivo desaparecido |

## Notas sobre V3

- **Migración V2→V3:** secuencial. Base nueva: se crea V1, V2 y luego V3.
  Base V2 existente: se añade la tabla `content_hashes` con sus índices.
- **Idempotente:** `CREATE TABLE IF NOT EXISTS` y `CREATE INDEX IF NOT EXISTS`.
  La migración puede ejecutarse múltiples veces sin romperse.
- **Reutilización de huellas:** La consulta `find_reusable_hash` busca
  `content_hashes` donde coincidan `absolute_path`, `file_size` y
  `file_modified_at`, independientemente de la sesión.
- **Duplicados exactos:** Se agrupan por `(hash_sha256, file_size)` donde
  `status IN ('computed', 'reused')` y `COUNT(*) > 1`. Archivos sin huella
  válida no se consideran duplicados.

## Flujo de cálculo de huellas

```
1. Escaneo completado → sesión guardada en scan_sessions y scan_entries
2. Usuario pulsa "Calcular huellas" en la GUI
3. HashWorker (QThread) inicia:
   a. Carga scan_entries filtrando solo files indexed
   b. Por cada archivo:
      - Busca huella reutilizable por absolute_path + size + mtime
      - Si no existe → StreamingHasher.compute_hash():
        * is_symlink() → skip
        * stat previo
        * SHA-256 por bloques de 64 KB
        * stat posterior
        * Si cambió → modified_during_read
      - Guarda en content_hashes (transacción por lote)
   c. find_duplicates agrupa por hash_sha256 HAVING COUNT(*) > 1
4. GUI muestra: conteos de calculadas/reutilizadas/errores, pestaña de duplicados
```

## OCR y `text_extractions`

El OCR reutiliza la tabla `text_extractions` sin migración:

- Cada resultado OCR se guarda como fila nueva con `extractor = "pdf_ocr"`,
  `extractor_version = <versión del motor>` y `needs_ocr = 0`.
- La reutilización se basa en `find_reusable_extraction` con una
  `config_version` propia del OCR (`ocr_config_version` en
  `extraction_config.py`: modo, DPI, PSM, idioma y versión del motor). No
  invalida la caché de la extracción de texto normal.
- `get_text_extraction_by_path` (nueva) y `get_text_extraction_by_entry`
  ordenan por `needs_ocr ASC, extraction_id DESC`: el contenido OCR tiene
  preferencia sobre la fila `NEEDS_OCR` original al consultar contenido.
- Si `tesseract-ocr` no está instalado, `OcrTextUseCase` devuelve
  `OcrResult` con `engine_available = False` sin escribir nada.
