# Estado del proyecto

**Último hito estable:** Huellas SHA-256 y duplicados exactos.

**Comprobaciones actuales:** pytest, Ruff, mypy.

## Completado

- Estructura del repositorio
- Paquete Python (`folderscribe`)
- Documentación inicial (PRODUCT.md, MVP.md, AGENTS.md)
- Python 3.12
- pytest, Ruff y mypy configurados
- Comando `folderscribe`
- Comando `folderscribe scan RUTA`
- Inventario recursivo seguro
- Formatos compatibles: PDF, DOCX, TXT, Markdown
- Enlaces simbólicos omitidos
- Errores parciales controlados
- Exclusiones de directorios técnicos
- Detección de proyectos de código
- Índice local SQLite (metadatos del inventario)
- Persistencia de sesiones, entradas y errores
- Parámetro `--database` para ruta personalizada
- Parámetro `--exclude` para exclusiones personalizadas por patrón
- Parámetro `--no-text` para omitir extracción de texto
- Parámetro `--no-hash` para omitir cálculo de huellas
- Persistencia de reglas de exclusión en SQLite
- Migración de esquema V1 a V2, V2 a V3, V3 a V4
- ExclusionMatcher en el dominio
- Pruebas automatizadas (~270+ pruebas)
- Interfaz gráfica (PySide6): selector de carpeta, exclusiones, escaneo, tabla de resultados, filtros, pestaña de errores, panel de contenido, extracción de texto
- **Cálculo de huellas SHA-256 por streaming** (bloques de 64 KB)
- **Detección de duplicados exactos** agrupados por hash y tamaño
- **Reutilización de huellas** cuando tamaño y fecha de modificación no cambian
- **Detección de modificaciones durante lectura**
- **Migración V3** con tabla `content_hashes` e índices
- **Botón "Calcular huellas"** en GUI con progreso determinado y cancelación
- **Pestaña de duplicados** con grupos y espacio redundante
- **Filtro "duplicados"** en la tabla de resultados
- **Separación de responsabilidades:** `StreamingHasher`, `ComputeHashesUseCase`, `HashWorker`
- **Extracción local de texto** sin OCR para PDF, DOCX, TXT, Markdown
- **Migración V4** con tablas `text_extractions` y `scan_entry_extractions`
- **Reutilización de extracciones** por SHA-256 con invalidación
- **Heurística NEEDS_OCR** versionada y centralizada
- **Cuatro niveles de privacidad:** Excluir, Solo metadatos, Local, Completo
- **Panel de contenido** en GUI con carga bajo demanda (5.000 caracteres)
- **ExtractTextUseCase** con cancelación, lotes y progreso
- **OCR local** para PDFs escaneados con Tesseract + PyMuPDF
- **Modos rápido (150 DPI/PSM 3) y completo (300 DPI/PSM 6)**
- **OcrTextUseCase** con reutilización, cancelación, lotes y progreso
- **Botón "OCR"** en GUI con selector de modo y worker en QThread
- **Flag `--ocr-mode fast|full`** en la CLI (off por defecto)
- **Degradación elegante** si tesseract no está instalado
