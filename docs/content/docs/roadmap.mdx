# Roadmap

1. **Exclusiones técnicas y proyectos** — Completado.
2. **Índice local SQLite** — Base de datos ligera para almacenar inventarios,
   metadatos e historial. Completado.
3. **Exclusiones personalizadas** — El usuario puede configurar sus propias
   exclusiones por nombre o patrón mediante `--exclude`. Completado.
4. **Interfaz gráfica mínima** — GUI de escritorio con PySide6 para escanear
   carpetas, configurar exclusiones y revisar el inventario. En desarrollo.
5. **Hashes y duplicados exactos** — Detección mediante SHA-256.
6. **Extracción de texto** — Contenido textual de PDF, DOCX, TXT y Markdown.
7. **OCR** — Extracción de texto en PDF escaneados (rápido y completo).
   Completado.
8. **Clasificación y propuestas** — Sugerencias de carpeta de destino y
   renombrado basadas en contenido.
9. **Planes reversibles** — Ejecución supervisada con capacidad de deshacer.
