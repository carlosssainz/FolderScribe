# Roadmap

1. **Exclusiones técnicas y proyectos** — Completado.
2. **Índice local SQLite** — Base de datos ligera para almacenar inventarios,
   metadatos e historial. Completado.
3. **Exclusiones personalizadas** — El usuario podrá configurar sus propias
   exclusiones por nombre o patrón.
4. **Hashes y duplicados exactos** — Detección mediante SHA-256.
5. **Extracción de texto** — Contenido textual de PDF, DOCX, TXT y Markdown.
6. **OCR** — Extracción de texto en PDF escaneados (rápido y completo).
7. **Clasificación y propuestas** — Sugerencias de carpeta de destino y
   renombrado basadas en contenido.
8. **Planes reversibles** — Ejecución supervisada con capacidad de deshacer.
9. **Interfaz gráfica** — UI para facilitar la revisión y aprobación.
